VEXSHOT ROULETTE - installable app files (flat version: no folders)
====================================================================

All 9 files go in the SAME place, with no subfolders:
  index.html, manifest.webmanifest, sw.js,
  icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png, favicon-64.png,
  README.txt (optional)

GitHub Pages
  1. Repository > Add file > Upload files, and select every file above at once.
  2. Commit changes.
  3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
  4. Open https://YOUR-USERNAME.github.io/REPOSITORY-NAME/ in Chrome (Android) or Safari (iPhone).

Updating
  After you change index.html, change 'vexshot-v2' in sw.js to 'vexshot-v3' (and so on)
  and upload both files again.
